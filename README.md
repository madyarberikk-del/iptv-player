# IPTV Player (Android)

Простой IPTV-плеер для телефона: плейлисты M3U/M3U8 по ссылке или из файла, группы, поиск, избранное, полноэкранный просмотр (Media3/ExoPlayer, HLS и MPEG-TS).

Приложение не подключается ни к каким внутренним системам; плейлист, избранное и последний канал хранятся только на телефоне.
Используйте только плейлисты, на которые у вас есть права.

## Сборка APK

**В облаке (GitHub Actions):** любой push в репозиторий запускает `.github/workflows/build.yml`.
Готовый APK — во вкладке *Actions* → последний запуск → *Artifacts* → `iptv-player-apk`.

**Локально:** нужны JDK 17 и Android SDK (platform 34), затем `./gradlew assembleDebug`.
APK: `app/build/outputs/apk/debug/app-debug.apk`.

## Установка на телефон

1. Скопировать `app-debug.apk` на телефон.
2. Открыть файл, разрешить установку из этого источника.
3. В приложении: меню → «Плейлист по ссылке» или «Открыть файл M3U».

Управление: нажатие на канал — просмотр, долгое нажатие — в избранное; в плеере кнопки ⏮ ⏭ переключают каналы.
